# OpenCV 红色目标检测与二维运动预测

使用 C++ 和 OpenCV 在合成视频中检测、跟踪红色目标，并用相邻两次实际位置的位移预测下一帧位置。绿色框表示当前检测到的目标，黄色点表示预测位置。目标短暂消失时，程序在设定的等待时间内继续外推搜索中心，并单独统计找回误差。

## 环境与运行

项目使用 CMake、C++14 和 OpenCV。在项目根目录运行：

    cmake -S . -B build
    cmake --build build
    ./build/main

默认输入为 `data/test10_complex_red_challenge.avi`，输出为 `data/result_complex_red_challenge_01.avi`。默认素材为 640×480、10 FPS。更换素材时，在 `main.cpp` 中修改输入路径、输出路径、`fps`、`width`、`height`；`HoldSeconds` 控制目标丢失后的等待秒数。输出文件名建议另取新名字，以免覆盖旧结果。生成的 `data/result_*` 文件已被 `.gitignore` 排除。

## 方法

1. 转到 HSV 色彩空间，用两段色相阈值提取红色区域，做形态学开运算，并过滤面积小于 500 的轮廓。
2. 初次检测时选面积最大的候选；跟踪期间选离搜索中心最近且距离不超过 80 像素的候选，只给最终选中的候选画框。
3. 连续检测到目标时，根据中心位移外推下一帧位置，并统计有效预测次数、平均欧氏误差和最大误差。
4. 暂时未检测到目标时，保留最后一次实际位置和位移，用丢失帧数外推搜索中心。超过等待帧数才确认丢失；找回后分别统计实际找回次数、可计算误差的样本数和平均找回误差。

## 合成测试素材

| 文件 | 用途 |
| --- | --- |
| `test1.png`、`test2_noise.png`、`test3_multi_red.png` | 基础颜色、噪点和多目标图像；当前主程序只读取视频 |
| `test4_red_motion.avi` | 单目标匀速运动 |
| `test5_red_speedchange.avi` | 变速及停止 |
| `test6_red_gap.avi` | 目标短暂缺失 |
| `test7_two_red_targets.avi` | 两个红色目标 |
| `test8_area_swap.avi` | 两个目标面积互换 |
| `test9_target_disappear_distractor.avi` | 原目标消失、远处红色干扰目标仍在 |
| `test10_complex_red_challenge.avi` | 噪点、短暂消失、大小变化、多个同色目标和异色干扰 |
| `test10_ground_truth.csv` | test10 的逐帧目标位置与可见性，帧号从 0 开始 |

这些素材均为合成数据。当前主程序默认读取 test10；切换其他素材需要同步检查输入路径和视频参数。

## 局限

- 颜色、面积和 80 像素距离门限面向合成素材，尚未在真实场景验证。
- 靠距离选择候选不能保证目标身份；预测位置附近若有另一红色目标，仍可能误锁。
- 速度按每帧位移估计，假设帧间隔稳定；变速、遮挡期间运动变化会增大误差。
- 目前只做二维位置预测，尚未实现 PnP 位姿解算和三维预测。
