# OpenCV 红色目标检测与二维运动预测

使用 C++ 和 OpenCV 在合成视频中检测红色目标、框选跟踪目标，并依据相邻两帧的中心位移预测下一帧的图像位置。绿色框和“RED”表示当前选中的目标，黄色点表示下一帧的预测中心。

## 环境与运行

已在 Ubuntu 22.04、OpenCV 4.5.4、CMake、C++14 环境中验证。在**项目根目录**运行：

    cmake -S . -B build
    cmake --build build
    ./build/main

默认输入为 `data/test5_red_speedchange.avi`，输出为 `data/result_red_speedchange_02.avi`。程序逐帧打印中心位置、位移、下一帧预测位置与预测误差；结束时打印处理帧数、有效预测次数、平均欧氏误差和最大单帧误差。视频输出为 640×480、10 FPS、MJPG。更换素材时需在 `main.cpp` 中修改输入和输出路径、重新构建；输出文件名应使用新名字，避免 `VideoWriter` 覆盖旧结果。

## 方法

1. 转到 HSV 色彩空间，用 0–10 和 170–179 两段色相阈值提取红色区域，做形态学开运算，并过滤面积小于 500 的轮廓。
2. 无上一帧目标时选面积最大的候选；有上一帧目标时，选与上一帧中心最近、且单帧位移不超过 80 像素的候选。只给最终选中的候选画绿色框。
3. 用当前中心与上一帧中心的位移外推下一帧中心；下一帧到来后计算实际中心与上次预测中心的欧氏距离。若无合格目标，清除历史状态；后续可重新选目标。

## 合成测试素材

| 文件 | 用途 |
| --- | --- |
| `test1.png`、`test2_noise.png`、`test3_multi_red.png` | 基础颜色、噪点和多目标图像；当前主程序只读取视频 |
| `test4_red_motion.avi` | 单目标匀速运动 |
| `test5_red_speedchange.avi` | 变速及停止；30 帧、28 次有效预测，平均误差 0.5 像素、最大误差 10 像素 |
| `test6_red_gap.avi` | 目标缺失三帧后重新出现；30 帧、23 次有效预测，平均及最大误差均为 0 |
| `test7_two_red_targets.avi` | 双目标，检查首次按面积选择 |
| `test8_area_swap.avi` | 双目标面积互换，检查继续跟踪原目标 |
| `test9_target_disappear_distractor.avi` | 原目标消失但远处红色干扰目标仍在；先报丢失，下一帧重新选目标 |

这些素材均为程序生成的合成数据。以上结果来自对应素材的独立构建运行；运行其他素材需按前述方式切换输入文件。

## 局限

- 颜色阈值、面积门限、80 像素位移门限及固定输出参数面向这些合成素材，尚未在真实场景验证。
- 当前跟踪不维护目标身份：原目标消失后，下一帧可能重新锁定另一个红色目标。
- 预测基于相邻帧位移，默认帧间隔固定；变速或突然停止时误差会增加。
- 尚未实现 PnP 位姿解算与三维运动预测。
