# OpenCV 红色目标检测与二维运动预测（第一版）

使用 C++ 和 OpenCV 在视频中检测红色目标、画框，并根据相邻两帧的中心位移预测下一帧中心。绿色框表示检测到的红色区域；黄色点表示对下一帧中心的预测。

## 环境与运行

已在 Ubuntu 22.04、OpenCV 4.5.4、CMake 和 C++14 环境中测试。需要系统能找到 OpenCV 的 CMake 配置。

在**项目根目录**执行：

    cmake -S . -B build
    cmake --build build
    ./build/main

程序默认读取 `data/test8_area_swap.avi`，生成 `data/result_area_swap_01.avi`，并在终端输出目标中心、位移、下一帧预测位置和预测误差。输入视频是 640×480、10 FPS；输出固定为同样的尺寸与帧率，编码为 MJPG。运行其他素材时，先在 `main.cpp` 中修改输入路径和输出路径，再重新构建。输出文件名不要与已有结果重名，因为 VideoWriter 会覆盖它。

## 合成测试素材

| 文件 | 用途 |
| --- | --- |
| `test1.png`、`test2_noise.png` | 基础色块与噪点；当前主程序读取视频，不直接读取这两张图片 |
| `test3_multi_red.png` | 双红目标与干扰块；当前主程序不直接读取图片 |
| `test4_red_motion.avi` | 单目标匀速运动 |
| `test5_red_speedchange.avi` | 目标加速、停止，观察预测误差 |
| `test6_red_gap.avi` | 中间连续三帧没有红色目标，检查跟踪重置 |
| `test7_two_red_targets.avi` | 双目标，检查首次选择较大目标 |
| `test8_area_swap.avi` | 双目标面积互换，检查是否继续跟踪上一目标 |

这些素材均为程序生成的合成数据。构建目录、可执行文件和 `data/result_*` 输出已加入 `.gitignore`。

## 当前实现与局限

- HSV 双段红色阈值、形态学开运算、轮廓与面积筛选、目标框选。
- 首次从多个目标中选面积最大者；有上一帧中心后，选距离上一帧中心最近者。
- 用相邻帧中心位移预测下一帧中心，输出预测误差；丢失全部目标时清除历史状态。
- 阈值、最小面积 500、输出尺寸和帧率面向这些合成素材，未在真实场景验证。
- 如果原目标消失但画面仍有其他红色目标，最近目标规则可能错误切换。位姿解算和三维运动预测尚未实现。
